# Pinpoint Frontend

Lightweight React + Tailwind CSS client for the **Pinpoint** active-recall and memory-palace study app.

## Implemented Features (Home Dashboard)

As specified in [README.md](../README.md):

1. **Student Greeting & Status**: Personalized greeting with streak counter and study goals.
2. **Nearest Exam Countdown**: Dynamic real-time countdown timer down to seconds for upcoming exams.
3. **Mastery Rings for Topics & Units**: Custom SVG circular progress rings showing active recall mastery % for every topic.
4. **Auto-Generated Task List**: Task list dynamically derived from gap analysis (teach back aloud, pin gaps to memory palace, speed recall review, and add notes).
5. **Memory Palace Showcase**: Cards showing palace spaces, flag counts, and recent training recency.
6. **Quick Topic Material Modal**: Interface for uploading 2-page documents/photos for AI key-point extraction.

## Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Lucide Icons**

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

The app will run at `http://localhost:5173`.
